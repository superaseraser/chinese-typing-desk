中文输入小工具 · 离线版

1. 将整个 ZIP 压缩包解压到任意文件夹。
2. 使用较新版本的 Chrome 或 Edge 打开 Chinese-Typing-Desk-Offline.html。
3. 等待“中文输入已就绪”，输入 nihao，按空格选择“你好”。
4. 点击“复制文字”，粘贴到其他应用；若浏览器不允许自动复制，按提示使用 Ctrl+C。

不需要联网，不需要安装软件，不需要启动本地服务器。
输入引擎、拼音词库和整句模型全部包含在 HTML 文件中。
默认中文界面，右上角可切换 English。界面语言切换不会清空文字。
本工具仅在自身输入框内生效，不会添加 Windows 系统输入法。
文字不会保存，关闭或刷新前请先复制。

需要支持 WebAssembly、模块 Worker、DecompressionStream 的浏览器。
如果工作或学校的策略限制浏览器运行脚本，请联系 IT。

MSIME 的许可证和第三方声明见 MSIME-LICENSE.txt 和 MSIME-NOTICE.md。
engine-source 包含发布的 JavaScript 源文件；MSIME-source.tar.gz 包含对应引擎源代码。
来源：https://github.com/metasequoiaime/msime

Chinese Typing Desk · Offline edition

Extract the ZIP, then open Chinese-Typing-Desk-Offline.html in a recent Chrome or Edge.
No connection, installation, or local server is required. The engine, dictionary, and model are embedded.
Wait for the ready indicator, type nihao, press Space, and copy the resulting Chinese text.
If automatic copying is unavailable, use Ctrl+C after the text is selected.
Use the top-right button to switch the interface to English. Copy your work before closing.
